# Feedback / フィードバック

OpenQuest is in development. We welcome concrete examples of the work you want to organize, questions about the concept, and reports of confusing explanations.

OpenQuestは開発中です。整理したい仕事の具体例、構想への質問、説明の分かりにくい点を歓迎します。

Open the **Issues** tab and choose **Product feedback / 製品へのフィードバック**. Please include:

1. The work you are trying to do / どんな仕事を進めたいか。
2. What makes it difficult today / 今困っていること。
3. The behavior or demonstration you would like / 見たい動作や改善。

Refer to [STATUS.md](STATUS.md) before reporting a planned capability as a broken released feature. This introduction repository does not accept implementation pull requests at this stage.

未実装の項目は[STATUS.md](STATUS.md)に記載しています。この紹介用リポジトリでは、現在は実装コードのPRを受け付けていません。

Use fictional or redacted examples. Do not post API keys, passwords, private conversations, customer data, or confidential repository content in public Issues. For a report that requires private handling, use the contact route on the [Toppy website](https://www.toppymicros.com/).
